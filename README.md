# 🚀 Stop Joking — Учебный Портал



> **Сфокусируйся на учебе. Время идет.**  
> Одностраничный портал для студентов колледжа Газпрома: расписание, заметки и таймер фокуса в одном месте.

---

## 📖 О проекте

**Stop Joking** — это легковесный учебный дашборд, созданный для студентов групп **26 АТП-2Бо** и **26 АТП-3Бо** (1 курс) Волгоградского колледжа Газпрома.  
Проект решает простую задачу: собрать в одном интерфейсе всё, что нужно для учёбы — расписание, быстрые заметки и таймер, который помогает не отвлекаться.

Сайт полностью статичен (HTML + CSS + JS), не требует сервера и может быть развёрнут на GitHub Pages.

---

## ✨ Возможности

- 📅 **Расписание занятий** — переключение между группами и неделями.
- 📝 **Мои заметки** — быстрое сохранение мыслей прямо в браузере (LocalStorage).
- ⏳ **Таймер фокуса** — обратный отсчёт, который напоминает: «Время идет».
- 🎨 **Визуальные эффекты** — переключение «стеклянного» интерфейса (Glassmorphism) и пиксельного шрифта в стиле Minecraft.
- 📱 **Адаптивность** — удобно пользоваться как на ПК, так и на телефоне.
